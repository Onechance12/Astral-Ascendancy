# Resource Costing and Card Value System

## Goal

Every card needs a strict cost/value identity.

Astral Ascendancy should not rely on vibes like "this feels like a 3-cost card." Each card should have:

- A paid resource cost
- A faction/world requirement if needed
- A value score
- A reason it is above or below baseline
- A target turn
- A power band
- A clear role on the 5x5 board

This lets us balance the game like a tactical card game, not a pile of cool effects.

## Research Lessons

### Renewable Energy Is Easy To Read

MARVEL SNAP uses Energy as the cost to play cards. It starts at 1 on turn 1, increases by 1 each turn, and does not carry over. That creates clean turn planning.

Astral lesson:

- Use one obvious universal match resource.
- Do not make the first prototype resource UI overloaded.

### Lands Create Identity But Can Create Bad Draws

Magic uses lands to generate colored mana for spells. This creates deckbuilding depth and faction/color identity, but it can also create games where the player cannot play.

Astral lesson:

- Worlds should matter.
- Worlds should not make the player unable to play normal cards.
- Use world/faction Affinity as a requirement or bonus layer, not the only way to pay basic costs.

### Banked Overflow Reduces Feel-Bad Turns

Legends of Runeterra uses banked spell mana, letting some unused mana help later spells. This softens bad turns without removing cost tension.

Astral lesson:

- Consider a small banked reserve for anomalies/commander abilities later.
- Keep alpha simple unless the prototype feels too punishing.

### Board Resource Nodes Make Positioning Matter

Faeria ties board development and resource collection together through land placement and wells. Duelyst uses mana springs to create early board fights.

Astral lesson:

- Center/world control should create extra resources.
- Structures and worlds should create economy through board risk.
- Resource generation should be visible on sectors.

## Astral Resource Model

Astral uses four resource layers.

## 1. Resonance

Resonance is the universal match energy.

Used to:

- Play entities
- Play worlds
- Build structures
- Play anomalies
- Attach armor/weapons/relics
- Activate some commander abilities

Rules:

- Starts at 1 on turn 1.
- Increases by 1 each turn.
- Caps at 10.
- Refills at start of turn.
- Does not carry over by default.

Reason:

- This is the readable "what can I play this turn?" number.

## 2. Affinity

Affinity is a requirement, not usually a spent currency.

It represents whether the battlefield supports a faction's advanced technology, biology, ritual, or command network.

Generated by:

- Commander faction: +1 matching Affinity baseline
- Controlled matching world: +1 matching Affinity
- Controlled matching structure: +1 matching Affinity if the structure is active
- Some relics or campaign powers

Used by:

- Rare/Holo/Mythic faction cards
- Advanced worlds
- Strong structures
- Commander ascension effects

Example:

- Vael'Sun gives 1 Solari Affinity.
- Controlling Solar Forge Moon gives +1 Solari Affinity.
- Controlling Dawn Spire gives +1 Solari Affinity while active.
- A card requiring Solari Affinity 2 can be played if Vael'Sun is your commander and you control a Star world.

Reason:

- Creates faction identity without making players draw land to play the game.

## 3. Materials

Materials are generated by worlds and structures.

They can exist in two forms:

- Temporary match material
- Persistent domain material

Alpha match materials:

- Plasma
- Biomass
- Data
- Verdance
- Ember
- Aether

Used to:

- Pay kicker costs
- Activate structures
- Upgrade worlds
- Trigger stronger modes
- Fuse or craft cards outside battle

Alpha rule:

- Do not require material for every card.
- Use material costs for strong optional effects, upgraded worlds, or late-game power.

Reason:

- Materials make worlds feel economically real without turning the hand into a spreadsheet.

## 4. Influence

Influence is both victory pressure and strategic economy.

Generated by:

- Controlling center sectors
- Keeping structures alive
- Completing world objectives
- Commander and faction effects

Used for:

- Ascendancy win condition
- Some Singularity/Genesis effects
- Campaign reward scaling

Rule:

- Influence is usually not spent in normal alpha play.
- If a card spends Influence, it must be rare and dramatic.

Reason:

- Spending your win condition is interesting but risky. Use sparingly.

## Resource UI Priority

Alpha battle UI should show:

1. Resonance
2. Commander HP
3. Influence
4. Relevant faction material only when generated
5. Affinity only when a card needs it or on debug panel

Do not show all currencies all the time.

## Cost Formula

Each card gets a target value score.

```txt
card_value
  = stat_value
  + keyword_value
  + effect_value
  + terrain_value
  + structure_or_world_value
  + flexibility_value
  - setup_penalty
  - self_risk_penalty
  - delayed_value_penalty
```

Then compare to paid cost:

```txt
cost_budget
  = resonance_cost_budget
  + affinity_requirement_value
  + material_cost_value
  + board_requirement_value
```

Balanced if:

```txt
card_value is within target range for cost_budget and rarity
```

## Stat Value

For entities:

```txt
stat_value = attack + hp
```

Adjustments:

- High attack and low HP is aggressive but fragile.
- Low attack and high HP is defensive and board-control focused.
- 0 attack structures use structure HP budget instead.

## Keyword Value

Approximate starting values:

- Shield 1: +1.0
- Guardian: +1.0
- Strike First: +1.0
- Ranged 2: +1.5
- Flying: +1.5
- Regenerate 1: +1.5
- Overwhelm: +1.0
- Blink: +1.5
- Forecast 1: +1.0
- Spawn 1/1: +2.0
- Area damage 1: +2.0
- Area damage 2: +4.0
- Structure trigger each turn: +2.0 to +5.0

These are not final. They are a starting valuation system.

## Setup Penalties

Subtract value when a card needs help.

Examples:

- Requires matching world: -1.0
- Requires connected worlds: -2.0
- Requires damaged ally: -1.0
- Requires empty adjacent sector: -0.5
- Delayed until next turn: -1.0 to -2.0
- Self-damage: -1.0
- Structure must survive: -2.0

## Rarity Value Bands

Rarity should increase complexity and ceiling, not just raw efficiency.

Common:

- Target: 90% to 105% of baseline

Uncommon:

- Target: 95% to 110% of baseline with synergy

Rare:

- Target: 100% to 115% of baseline when built around

Holo:

- Target: 105% to 120% of baseline with visible setup or counterplay

Mythic:

- Target: 110% to 130% of baseline but conditional or one-copy-limited

Singularity:

- Target: not baseline-efficient. It should bend rules and create objectives.

## Resonance Cost Budget

Starting baseline:

- Cost 1: value 3 to 4
- Cost 2: value 5 to 6.5
- Cost 3: value 7 to 8.5
- Cost 4: value 9 to 10.5
- Cost 5: value 11 to 13
- Cost 6: value 13 to 16
- Cost 7+: only for Mythic/Singularity effects

## World Costs

Worlds are not free.

Basic rule:

- Playing a world costs Resonance.
- Playing stronger worlds can require Affinity.
- Upgrading worlds can require material.

World cost bands:

- Cost 1: Barren or simple neutral setup
- Cost 2: normal faction world
- Cost 3: stronger terrain with control effect
- Cost 4: Mythic world
- Cost 5+: Singularity objective world

Worlds must have counterplay:

- Occupy
- Corrupt
- Purify
- Destroy structure support
- Break connected sector chain
- Contest center

## Structures Costs

Structures use Resonance and board requirements.

Rules:

- Must usually be built on a controlled compatible world.
- Strong structures may require Affinity 2.
- Structures should usually do little immediately.
- Structure value comes from survival.

Structure cost bands:

- Cost 2: fragile utility structure
- Cost 3: core faction structure
- Cost 4: strong engine
- Cost 5+: boss/campaign or Mythic structures

## Material Costs

Material should not block early play.

Use material for:

- Activated abilities
- Upgraded modes
- World upgrades
- Fusion/crafting
- Singularity objectives

Examples:

- Spend 1 Plasma: give Shield 1.
- Spend 1 Biomass: spawn Broodling.
- Spend 1 Data: Scan then draw if sector has a structure.
- Spend 1 Verdance: regenerate 2.
- Spend 1 Ember: deal 1 to self and 2 to enemy.
- Spend 1 Aether: Blink or Forecast.

## Card Power Identity

Every card should be "powerful" in its own lane.

Not every card should be numerically strong. Every card should have a reason to exist.

Examples:

- Solari Acolyte: powerful because it teaches evolution and becomes efficient if protected.
- Void Broodling: powerful because death matters.
- Relay Grid: powerful because it changes where the player can deploy.
- Crimson Crucible: powerful because it turns damage into offense.
- Astral Gate: powerful because it rewrites movement.
- Worldheart Genesis: powerful because it creates an alternate objective.

## Alpha Rule

For the first playable version:

- Resonance is required to play every card.
- World cards cost Resonance.
- Structures cost Resonance and require a compatible controlled world.
- Rare+ faction cards can require Affinity.
- Materials appear on a few cards only.
- Debug mode should show value score and cost score.
